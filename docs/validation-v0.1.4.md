# 0.1.4 验证记录

2026-11-11，0.1.3 真实链接复测仍在第 2/18 张图片上传时返回 `4125014`。诊断为已经完整组合的标题 PNG，1360×100、13799 字节、单帧。此前截取范围问题已修正，但不能据此宣称 B站上传问题已解决。官方编辑器上传参数与扩展一致，正文前端未公开该服务端尺寸限制。

用户随后明确调整目标：小装饰无需保留，优先正文内容，不要求复刻微信公众号 HTML 的特殊排版。0.1.4 因此在解析阶段清理可确认的装饰，不再为「实验器材」旁的小装饰生成图片。标题、Q/A 编号和互动区正文仍为原生文字；纯色底、加粗、文字颜色等保留，避免白字丢失衬底。

清理范围限于明确的小型空装饰、Q/A 编号标签背景、无媒体且可确认的小尺寸平铺纹理。未知背景、可能有信息的图片、图形及公式不会被当作普通装饰删掉。正文图片、GIF 与公式计数单独回归；这是内容优先策略，不是任意页面排版逐像素还原。

五篇本地结构回归确认，仅剩正经玩文末带表情的图文段落需要局部转图；其余四篇不需局部转图。新增原生「实验器材」、Q1–Q12 文字断言，以及「厉娜」白字标题继承棕底断言。正文图片、GIF、公式和上下标统计未减少。

`npm test` 共 166 项全部通过、无跳过；`npm run check` 通过。实际上传与草稿回读验收仍需重新加载本版后进行，不能将离线测试等同于平台验收。
