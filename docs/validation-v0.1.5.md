# 0.1.5 验证记录

用户要求微信公众号图片下方的灰色小字进入 B站原生图片注释。本版按一图一图注关联，将普通灰色小字写入图片的 `comment`，不再重复输出为正文。

识别只处理紧随图片的第一个独立文字块，不跨过正文；多图共用说明、标题、署名和参考资料不作单图自动关联。清理中保留图注继承的样式；再次清理不改变结果。B站原生图注仅支持最多 100 个 UTF-16 代码单元的纯文字，因此超长、公式、上下标、强调或彩色图注完整保留在图片下方正文并提示，不截断或静默去掉语义。
