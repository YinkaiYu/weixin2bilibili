# 物理所B站导入微信文章

直接嵌入 B站原生专栏编辑页的 Edge / Chrome 插件。导入公众号文章后，在 B站继续修改、设置和发布。无需服务端，不会自动发布。

默认以内容为主：清理已确认的拼贴装饰、章节小图标、编号标签背景和明确的卡片纹理，保留原生可编辑文字及正文图片、动图、公式、上下标、加粗和文字颜色，不复刻公众号的特殊容器排版。

## 安装

1. 在 Edge 地址栏输入 edge://extensions。
2. 打开「开发人员模式」，点击「加载解压缩的扩展」。
3. 选择本项目的 extension 文件夹（里面有 manifest.json）。也可以解压 dist 中的 ZIP 后选择解压目录。
4. 在 Edge 正常登录 B站。安装后不需要运行 Node 或本地服务器。

更新时，用新版本覆盖原安装目录，在 Edge 扩展页面点击该插件的「重新加载」，再刷新 B站编辑页。直接加载本项目 extension 文件夹的用户，只需重新加载和刷新。

## 使用

打开 B站专栏编辑器，点击「导入公众号」，粘贴链接，再点击「导入为新草稿」。也可以在公众号文章页面点击扩展图标，自动带入链接。

导入完成后直接打开 B站原生草稿：标题、正文、封面、原创声明、文集都在那里修改，检查后由你发布。没有独立的排版编辑界面。

遇到微信验证页时，先在 Edge 正常打开原文完成验证再试；也可以在导入面板的「更多」里选择保存的 HTML 网页和配套资源文件夹。插件不执行保存网页中的脚本。

## 已实现的处理

- 正文图片和封面全部转存到 B站 CDN，所有图片成功后才保存草稿。失败不删图、不保留微信图片链接冒充成功。
- 保留 GIF 原始字节，核对上传后的帧数、时序；动画检查失败时停止。
- 图片紧随的灰色小字进入对应图片的 B站原生注释，避免正文重复。超过 100 字符，或含公式、上下标、加粗、彩色强调等原生注释无法保留的内容时，完整保留在图片下方并提示；不截断，不跨正文关联。
- 有 LaTeX 源码的公式使用 B站原生公式；上下标转换成原生行内公式。加粗、颜色等文字样式使用原生节点。
- 非原生支持的少量背景纹理、行内静态图片等局部输出高清图片，其他正文保持原生。局部图片在 B站中需要通过替换图片修改；包含动画的局部不会被截成静态图。
- 清除外链但保留文字与图片；清除裸网址、空行和空白段落。
- 从「上期回顾」「往期回顾」「近期热门文章Top10」栏目标题开始截断。普通句子里提到这些词不触发。
- 使用公众号封面作为自定义封面，默认声明原创；从页面及脚本中的公众号专栏元数据识别名称，与 B站文集同名且唯一时自动匹配。来源仍缺少名称时，以标题最后的 `| 栏目名` 或 `｜栏目名` 作候选，只作精确匹配；歧义时提示选择。
- 保存后重新读取，检查正文、图片顺序与图注、样式、公式、封面、原创和文集；读回失败仍提供已创建的草稿，避免重复创建。
- 不覆盖当前正在编辑的其他稿件；导入为新草稿。中断重试按账号和任务找回已有草稿，只重新核对，不覆盖你后来修改的内容；需要重新转换时可以明确选择「另建新草稿」。
- 字号按 B站原生档位适配：正文为 13 或 17，整段大字可转换为对应标题档位。与源字号不一致时提示，不承诺任意字号的像素级还原。

## 验证范围

五篇用户提供的本地样稿均纳入解析与原生结构回归，图片内容、图注关联、正文文字、公式、上下标及白字衬底分别检查。0.1.6 修正本地解析与 Chromium 对背景简写处理的差异，避免离线测试把真实背景漏掉。

- 「厉娜」按用户确认去掉 43 张拼贴/徽图/夹饰，保留 21 张正文图片、19 条图注及标题文字。规则限定已核验的素材与模板，不按尺寸删除未知图片。
- 「胶带」与「问答」的已确认装饰面板底色按内容优先策略清理，分别保留全部 4 和 26 个原生公式节点，不为这些面板增加截图。
- 「闻气味」的「福利时间」保留为一行可编辑标题。
- 专栏脚本元数据即使没有渲染为页面合集文字，也能提取并精确匹配。

真实账号中，「手机的清晰度 | 正经玩」已完成直接链接导入、图片上传、保存回读及原生界面核对；随后通过原生界面补齐的四条图片注释也已保存并重开确认。仅保存草稿，没有发布。

其余四篇的真实验收尚未全部完成：0.1.5「胶带」直接导入在背景公式检查处停止，0.1.6 已针对这一问题修复；本轮电脑操作工具中断，更新版仍待真实链接复测。本地结构、模拟上传/保存测试不能代替实际平台验收，具体记录见 docs/validation-v0.1.6.md。

B站没有为此提供稳定的公开第三方接口承诺。插件基于 2026-11-11 官方编辑器使用的原生 Opus 协议编写，网站更新后可能需要适配。无法表达的格式会明确提示，不承诺任意网页都能像素级无损同步。

## 数据和权限

跨站请求只由插件后台执行。页面只允许调用登录状态、文集、图片上传和草稿保存等指定操作；没有发布接口。账号密码不由插件获取；B站请求所需令牌只在本机后台使用，不暴露给页面、不记录日志。

图片只读取微信与 B站白名单域名；上传缓存和恢复信息保存在扩展本地存储。没有遥测、第三方服务端或远程执行代码。源码没有复制 Wechatsync 实现，参考了它的同步思路；包含的 html2canvas 使用 MIT 许可，见 THIRD_PARTY_NOTICES.txt。

## 开发

Node.js 20+。npm install 安装开发依赖，npm test 运行测试，npm run check 检查扩展文件，npm run package 打包。

本地存在「测试文章」文件夹时会运行真实样稿回归；ZIP 不包含用户网页、图片、账号信息或测试文件。协议来源与测试证据见 docs/native-schema.md 和 docs/article-audit.json。
