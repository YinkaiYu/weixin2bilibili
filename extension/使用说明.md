# weixin2bilibili

将微信公众号文章导入 B站专栏，生成可继续编辑的草稿。插件在浏览器中运行，无需安装其他开发工具；检查和发布在 B站原生编辑器中完成。

这是物理所内部的 B站运营工具，服务账号「二次元的中科院物理所」。下述默认规则按该账号的运营需求设置。

## 安装与更新

1. 在 [Releases](https://github.com/YinkaiYu/weixin2bilibili/releases) 下载最新版本的 `weixin2bilibili-v版本号.zip` 安装包。
2. 解压到固定文件夹，保留该文件夹供浏览器加载。
3. 在 Edge 地址栏输入 `edge://extensions`，打开「开发人员模式」，点击「加载解压缩的扩展」，选择含有 `manifest.json` 的文件夹。Chrome 对应页面为 `chrome://extensions`。
4. 登录 B站，打开专栏编辑页。

更新时，将新版本解压到原安装目录，替换扩展文件；在扩展管理页点击「重新加载」，再刷新 B站编辑页。

## 导入文章

1. 在 B站专栏编辑页点击「导入公众号」。
2. 粘贴文章链接，点击「导入为新草稿」。也可以先打开公众号文章，再点击浏览器工具栏中的扩展图标带入链接。
3. 等待图片转存和草稿核对完成，打开草稿，在 B站原生编辑器中修改。
4. 检查标题、正文、封面、原创声明和文集，确认后自行发布。

插件使用公众号封面作为自定义封面，原创声明默认开启。微信专栏名与 B站文集做唯一精确匹配，另有「问答 → 问答Q&A」映射；未匹配或有歧义时不自动选择。请按文章实际情况调整。需要修改封面时，可通过「更多 → 下载封面图」保存封面。

导入创建新草稿。中断后重试会找回已有草稿并核对，不覆盖你后来做的编辑；需要重新转换时，可选择「另建新草稿」。

## 内容处理

- 保留正文图片、GIF 动图、公式、上下标、加粗和文字颜色；普通图注优先进入 B站原生图片注释。
- 文字尽量保持可编辑，字号和个别装饰标题适配到 B站原生样式。少量无法原生表达的静态局部会转成图片，处理情况可在「详情」查看。
- 清理已识别的开头横幅、标题装饰、纸纹、空行、微信组件提示、直播预约、独立立场声明和互动引导；从明确的回顾、福利互动、投票等尾栏开始截断。普通正文中的提及不触发。
- 清除普通外链。独立「原文链接」出处段经 B站识别认可后可点击；不支持或未确认时保留标题和完整网址供复制。

图片转存或动图检查失败时停止导入。无法完整转换的内容会提示或阻止导入，请结合「详情」检查草稿。

## 遇到问题

微信要求验证时，先在同一浏览器打开原文并完成验证，再重试。也可以将网页保存为完整 HTML，在「更多」中选择保存的网页和配套「资源文件夹」。

若草稿已保存但核对未通过，先查看已有草稿，再按提示处理。可以在 [Issues](https://github.com/YinkaiYu/weixin2bilibili/issues) 报告版本、操作步骤和错误提示，无需提供账号或完整文章；请移除凭据和私人信息。

文章处理在本地进行，素材上传和草稿保存使用当前登录的 B站账号，没有遥测或第三方服务端。代码许可、名称和图标的说明见 [BRANDING.md](https://github.com/YinkaiYu/weixin2bilibili/blob/main/BRANDING.md)，第三方依赖许可见安装目录中的 `THIRD_PARTY_NOTICES.txt`。
